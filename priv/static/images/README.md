# Images Directory

Place your app screenshot images here:

- `screenshot1.png` - Dashboard/stats view
- `screenshot2.png` - Analytics view
- `screenshot3.png` - Muscle engagement view
- `screenshot4.png` - Programs view
- `screenshot5.png` - Live workout view
- `muscle_engagement.png` - Muscle heatmap visualization

These images are referenced in the PhoneCarousel component in `lib/ykd_web/components.ex`.

## Image Requirements

- Format: PNG recommended
- Size: 1170x2532 pixels (iPhone mockup size)
- Optimize images for web (use ImageOptim, TinyPNG, etc.)

## Adding New Images

1. Place images in this directory
2. Reference them in templates using: `/images/your-image.png`
3. Images are served from `priv/static/images/`
