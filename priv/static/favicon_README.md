# Favicon

Place your favicon files here:
- `favicon.ico` - Main favicon (32x32 or 16x16)
- `favicon.svg` - SVG favicon (optional, for modern browsers)

You can generate favicons at:
- https://favicon.io
- https://realfavicongenerator.net

For the YKD branding, consider using:
- Lime green (#CCFF00) on dark background
- The YKD logo mark
- Simple, bold design
